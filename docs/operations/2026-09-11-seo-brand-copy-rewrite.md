## 2. 🔒 원문 공식 직함 10건 — 변경하지 않음 (별도 표시)

**JOB 10건**은 원문 공고 제목 자체에 금지 표현이 있다. 채용 공고의 **공식 직함·기관 유형**이라
원문을 고치면 공고 사실이 달라진다. **그대로 둔다.**

| 유형 | 건수 | 예 |
|---|---:|---|
| 직무·기관 유형이 제목에 포함 | **10** | `노인주간보호 운전원` · `노인요양원 사회복지사` · `노인돌봄 생활지원사` |

이 10건은 수정 후에도 **렌더되는 SEO title 에 금지 표현이 남는다**(§5).
CSV 의 `jobOfficialTitlePreserved` · `sourceTitleHasBanned` 컬럼으로 식별된다.

> 추가로 **MAGAZINE 2건**도 원문 `title` 에 금지 표현이 있다(`노인일자리, 몇 살부터 신청할까` 등).
> 원문은 그대로 두되 그 글들의 `seoTitle` 은 우나어 필드라 정정했다 —
> 그래서 **렌더되는 `<title>` 에는 잔존하지 않는다.** 공개 화면에 보이는 글 제목은 그대로다.
> 원문 title 에 금지 표현이 있는 글은 **총 12건**(JOB 10 + MAGAZINE 2)이다.

## 3. 치환 원칙 — 사실은 보존하고 표현만 바꾼다

금지 표현(`시니어`·`어르신`·`노인`·`실버`)만 **문맥에 맞는 중립 표현**으로 바꿨다.
단어 대 단어가 아니라 **구절 단위**로 매칭해 문장이 어색해지지 않게 했다.

| 원 표현 | 정정 | 성격 |
|---|---|---|
| 어르신 곁에서 보람 있는 일 | 돌봄 현장에서 보람 있는 일 | 마케팅 카피 |
| 어르신 댁 방문하는 보람 있는 일 | 가정 방문 돌봄, 보람 있는 일 | 마케팅 카피 |
| 어르신 모시는 보람 있는 일 | 이용자를 모시는 보람 있는 일 | 마케팅 카피 |
| 독거 어르신 돌봄 / 독거노인 돌봄 | 1인 가구 이용자 돌봄 / 독거 가구 돌봄 | 대상 설명 |
| 4등급 어르신 돌봄 전문직 | 4등급 이용자 돌봄 전문직 | 장기요양 등급(사실) 보존 |
| 남성 어르신 요양보호사 채용 | 남성 이용자 담당 요양보호사 채용 | 대상 성별(사실) 보존 |
| 시니어 채용 / 일자리 / 구인 | 중장년 채용 / 일자리 / 구인 | SEO 키워드 |
| 시니어케어 | 방문케어 | 서비스 유형 |
| 노인복지센터 / 노인요양원 / 노인주간보호센터 | 재가복지센터 / 요양원 / 주간보호센터 | 기관 유형 |
| 재가노인복지 / 노인돌봄 / 노인 케어 | 재가복지 / 방문돌봄 / 재가 케어 | 서비스 유형 |
| 노인일자리사업 | 정부 공공일자리 사업 | **정부 제도명** — 검토 필요 |
| 실버타운 | 노후 전용 주거단지 | 주거 유형 — 검토 필요 |
| 실버케어 / 실버마을 | 요양케어 / 요양시설 | 서비스·시설 유형 |

## 4. 전수 검수 — 기계 치환이 어색해진 5건은 손으로 다듬었다

59건 전부 변경 전/후를 눈으로 확인했다. 일괄 치환으로 문장이 어색해진 **5건**을 수동 교정했다.

| 대상 | 문제 | 교정 |
|---|---|---|
| 매거진 ×2 | `노인일자리사업은 만 60세 이상부터` → 치환 시 **"만 60세 이상"이 중복** | 앞을 `정부 공공일자리 사업`으로 통일 |
| JOB ×1 | `실버마을` → `요양마을` 은 **실재하지 않는 조어** | `요양시설` |
| JOB ×1 | `1인 가구 …` 가 한 문장에 **두 번 반복** | 뒤쪽을 `독거 가구 돌봄` 으로(`독거`는 금지 표현이 아니다) |
| JOB ×1 | `중장년` 이 **연속 중복** | 앞을 `50·60대 일자리` 로 |

**수정 대상이 없는 1건**: JOB 1건은 금지 표현이 `seoTitle`(= 원문 공고 제목 복사본)에만 있고
`seoDescription` 에는 없다. 원문 보존 원칙에 따라 **수정하지 않는다**.

## 5. 수정 후 렌더 검증 — production `generateMetadata` 규칙 재현

정정안을 적용했다고 가정하고 production 규칙(커뮤니티·매거진·**JOB** 3분기)으로
`<title>`·`<meta name="description">` 을 재구성해 금지 표현 잔존을 셌다.

| 축 | 잔존 |
|---|---:|
| **우나어가 수정한 필드에서 잔존** | **0** ✅ |
| SEO `description` 잔존 | **0** ✅ |
| SEO `title` 잔존 | **10** — 전부 **원문 공고 제목 복사 유래**(§2) |

즉 **우나어가 쓴 카피에서는 금지 표현이 완전히 사라지고**, 남는 10건은 원문을 보존한 결과다.

## 6. 사람 검토가 필요한 30건

| 사유 | 건수 |
|---|---:|
| 회사 고유명에 금지 표현 포함 — 인용인지 일반 키워드인지 확인 필요 | 24 |
| 제도·기관 공식 표기 대체 — 검색 노출 영향 확인 필요 | (중복 포함) |
| 기계 치환이 어색해 수동 교정함 — 문구 승인 필요 | 5 |
| **고유 합계** | **30** |

🔴 **회사 고유명은 변경하지 않는다.** `솔밭재가노인복지센터`·`삼성재활실버케어` 같은
**회사·기관의 실제 이름은 사실**이다. CSV 의 `reviewReason` 에 해당 행을 표시했고,
정정안은 `seoDescription` 안의 **일반 키워드**만 바꿨다.
그 키워드가 실제로는 회사명 조각을 가리키는지 확인이 필요하다.

**제도 공식명 대체는 검색 노출 영향이 있다.** `노인일자리사업` 은 보건복지부 제도명이라
그 단어로 검색하는 사람이 있다. `정부 공공일자리 사업` 으로 바꾸면 브랜드 규칙은 지키지만
해당 검색어 노출은 잃는다. **이 트레이드오프는 창업자 결정 사항이다.**
