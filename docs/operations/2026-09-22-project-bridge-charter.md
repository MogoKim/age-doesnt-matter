## 1. 한 줄 정의

**우나어로 들어오는 사람을 전부 소란소란으로 보낸다. 최대한 많이.**

우나어는 커뮤니티로서는 포기하고, **SEO 자산 · 도메인 · 유입 깔때기로만 유지**한다 (병행 운영).
목적은 우나어 지표 방어가 아니라, **소란소란의 초기 사용자 확보 비용을 우나어가 대신 내는 것**이다.

## 2. 목표

**소란소란 도착 방문자를 최대화한다.** 목표 수치는 두지 않는다 — 많을수록 좋다.
GA4 `unao / *` 유입이 **주 단위로 늘고 있으면 성공**, 정체·감소면 구좌를 바꾼다.

**우나어 헌법 v5.0의 North Star(주간 재방문 참여 유저 수)는 이 프로젝트에 적용하지 않는다.**
단 헌법의 **네이버 Search Advisor 보호 조항은 그대로 유효**하다 (§5).

## 3. 계측 — GA4 **단독**. 다른 계측은 만들지 않는다

## 4. 구좌 인벤토리 (origin/main 실측)

**팝업은 코드 변경 0으로 오늘 띄울 수 있다.**

| 구좌 | 마운트 | 외부 도메인 | 개발량 |
|---|---|---|---|
| **Popup** (`PopupRenderer`) | `MainGroupClientOnly` = 메인그룹 **전 경로** | ✅ `window.open(linkUrl,'_blank','noopener')` **이미 동작** | **0** — 어드민 등록만 |
| **Notice 푸시·종알림** | 회원 전체 | `url` 필드 | **0** — 어드민 발송 |
| **TopPromoBanner** | 전 페이지 최상단 띠 | ✅ `isExternalHref` 분기 존재 — `https://` 면 `<a target="_blank">` | **0** — 어드민 설정만 |
| **HERO 배너** (`Banner` slot=HERO) | 홈 | `ctaUrl` | 0 — 어드민 |
| **AdBanner** | 목록·글상세 | `clickUrl` | 0 — 어드민 |
| 공지 게시글 | 커뮤니티 | 본문 링크 | 0 — 글 작성 |
| Footer / IconMenu / FAB | 전역 상시 | — | 소 |

**팝업이 이미 갖춘 운영 기능:** 경로 타겟팅(`targetPaths`) · 대상 분기(`ALL/HOME/COMMUNITY/JOBS/MAGAZINE/LIFE2/CUSTOM`) ·
기간 · 우선순위 · **하루 1회**(`showOncePerDay`) · **N일 숨김**(`hideForDays`)
**TopPromoBanner는 guest/member 설정이 분리**되어 있어 비회원/회원에 다른 문구를 줄 수 있다.

🔴 **TopPromoBanner는 `rel="noopener noreferrer"` 로 렌더된다 — referrer가 완전히 제거된다.**
팝업(`noopener`만)과 달리 **UTM이 없으면 GA4에서 "직접 유입(direct)"으로 잡혀 100% 실종된다.**
→ 푸시와 함께 **UTM 누락이 치명적인 2대 구좌**다.

> 참고 — 자사 전례: R8 측정에서 회원가입 유도 배너 클릭이 **30일간 0건**이었다.
> 배너 3종에 디자인 공수를 크게 쓰지 않는다. **팝업 + 푸시가 사실상 전부다.**

## 7. 충돌 지점

**`SignupPromptBanner`(`MainGroupClientBottom`)가 BRIDGE와 정면 충돌한다.**
이 배너는 **우나어 카카오 가입**을 유도하며, 카운트다운 후 **자동으로 가입 플로우를 시작**한다.
같은 사용자에게 "우나어에 가입해라"와 "소란소란으로 가라"를 동시에 제시하는 꼴이다.

- 이 배너가 바로 **R8에서 30일간 클릭 0건**이었던 그 배너다
- 단 `signup_banner_*` **A/B 실험이 진행 중**이라, 끄면 실험 데이터가 끊긴다
- → 창업자 판단 필요 (A-8): ① 그대로 둠 ② 끔 ③ BRIDGE 링크로 전환

**동시 노출 경쟁자** (`MainGroupClientBottom`): `SignupPromptBanner` · `PopupRenderer` · `PushPermissionToast`
`PushPermissionToast`는 `unao_admin_popup_visible` 키로 **이미 팝업에 양보**하도록 조정되어 있다 — 추가 작업 불필요.
홈에는 `HomePopupsClientOnly`(투표·설문·피드백 팝업)가 별도로 있어 **팝업 우선순위(`priority`) 조정이 필요**하다.

### 9-5. 🔴 푸시·종알림 — **보류 (법적 검토 필요)**

`/admin/push` 화면에 운영 규칙이 명시돼 있다:

> "공지·안내 등 **서비스성 내용만** (광고·혜택 문구 금지)"

**소란소란 유도는 다른 서비스로의 유인이라 광고성으로 판정될 여지가 있다.**
정보통신망법 제50조는 영리목적 광고성 정보 전송에 **사전 동의**와 제목의 **"(광고)" 표기**를 요구한다.
우나어 푸시 수신 동의가 광고 수신 동의까지 포함하는지 확인되지 않았다.

또한 이 화면은 **종알림과 OS 푸시를 분리 발송할 수 없다**(구독자에게 자동으로 함께 나간다).
발송은 **되돌릴 수 없다**.

→ **1차 집행에서 제외한다.** 팝업이 이미 메인그룹 전 경로에 도달하므로 푸시 없이도 도달률은 확보된다.
→ 재검토 조건: ① 수신 동의 범위 확인, 또는 ② 제목 `(광고)` 표기 수용, 또는 ③ 법무 확인.

## 12. 읽기 화면 분리 — SEO 유입 대응 (2026-09-22 2차)

### 놓쳤던 구멍

1차 집행(§11)은 **홈을 거쳐 오는 사람만** 가정했다. 실제로는 **검색으로 글 상세에 바로 착지**하는
유입이 있고, 그들에게는 홈 카드가 보이지 않는다.
게다가 F13(글 하단 CTA)의 비회원 분기를 제거해 놓고 **그 자리를 비워 뒀다** —
다 읽고 나면 아무 안내도 없이 나갔다.

또한 팝업이 `(main)` 그룹 전체에 붙어 있어 **글 상세에서도 2.5초 뒤에 떴다.**
읽으러 온 사람의 읽기를 끊는 배치다.

### 고친 것

| 화면 | 팝업 | 인라인 |
|---|---|---|
| 홈 · 목록 · 검색 등 **둘러보는 화면** | ✅ 뜬다 | 홈 카드 |
| **읽기 화면**(글/매거진/일자리/가이드/주제 **상세**) | 🚫 **뜨지 않는다** | ✅ 글 하단 카드 |

- `isReadingPage(pathname)` — 목록은 세그먼트 2개, 상세는 3개로 구분
  (`/community/free` = 목록 → 팝업 O · `/community/free/abc` = 상세 → 팝업 X)
- `SoranSoranPostCard` — 커뮤니티 글 상세 **`PostCTA` 바로 다음, 관련글 추천 앞**.
  다 읽고 댓글까지 본 직후 자리다. 모달처럼 끊지 않고 "다음 읽을 곳"으로 이어지게 둔다
- slot `postdetail` 신설 → GA4 에서 `unao / postdetail` 로 구분된다

### 팝업 디자인 재작업

밋밋한 흰 박스 → 브랜드 그라디언트 헤더(`--gradient-hot-from/to`) + 아이콘 + 강조 박스 + 큰 CTA.
모바일은 하단 시트처럼 올라오고(`items-end`), 데스크탑은 중앙 정렬. 진입 트랜지션 추가.
열려 있는 동안 `body` 스크롤을 잠근다.

⚠️ **색상을 하드코딩하지 마라** — `#FF6F61` 을 직접 적었다가 `design-token-audit --strict` 의
**R08 새 부채**로 CI 가 막았다. 기존 토큰 `--gradient-hot-from/to`(#FF6B6B→#FF8E53)로 교체해 해소했다.
(앞서 raw `<button>` 이 R11 로 막힌 것과 같은 계열의 실수다 — **공용 컴포넌트와 토큰을 먼저 찾아라.**)

### 남은 것

**매거진 상세**(`/magazine/[id]`)에는 넣지 않았다. 하단에 `NativeAdSlot`·AdSense 가 촘촘해
인접 관계를 건드릴 위험이 있다. 필요하면 광고 배치를 확인한 뒤 별도로 진행한다.

## 13. 공격적 모드 전환 (2026-09-22 3차 · 창업자 결정)

> "어차피 이제 우나어는 사망이다. 네이버에서 우리 브랜드를 노출시키고 싶지 않아 하는 것 같다."

§12 까지의 "읽기를 방해하지 않는다" 방침을 **창업자가 뒤집었다.** 남은 트래픽을 최대한 빨리 넘기는 쪽으로 간다.

| 항목 | §12 (이전) | §13 (현재) |
|---|---|---|
| 읽기 화면(글 상세) | 팝업 억제 | 🔴 **뜬다. 방해 감수** |
| 닫은 뒤 | 1일 / 7일 숨김 | 🔴 **저장 안 함 — 페이지 이동마다 다시 뜬다** |
| 하단 버튼 | "닫기" + "7일간 보지 않기" | 🔴 **X 하나, 가운데** |
| 클릭 영역 | CTA 버튼만 | 🔴 **X 를 뺀 카드 전체가 링크** |
| "우나어도 그대로 있습니다" | 표시 | 🔴 **삭제** |
| 노출 지연 | 2.5초 | 1.5초 |

홈 카드·글 상세 카드도 같은 방침으로 **카드 전체를 링크**로 바꿨다.

### 감수하는 위험 (알고 선택한 것)

🔴 **구글 모바일 인터스티셜 페널티.** `ssr:false` 라도 **Googlebot 은 JS 를 렌더링하므로
"크롤러가 못 본다"는 보장이 없다**(§11·§12 의 서술은 이 점에서 부정확했다 — 정정).
네이버 색인은 이미 0 이고 창업자가 우나어를 사실상 종료로 판단해 이 위험을 받아들였다.

🔴 **사용자 경험.** 페이지를 옮길 때마다 모달이 다시 뜬다. 잔여 회원의 이탈을 앞당길 수 있다.
이는 "우나어 커뮤니티 포기" 결정(§0)의 연장선이다.

**여전히 지키는 것**: `sitemap`·`robots`·`canonical`·일반 `meta robots` 는 건드리지 않는다(CI `seo-guard` 준수).
배경(오버레이) 클릭과 `ESC` 는 닫기로 남겼다 — 모달에서 빠져나갈 길까지 막으면 기만이 된다.

### 되돌릴 때

계약 테스트 `bridge-links.test.ts` 의 **"공격적 모드 — 노출 억제 장치가 없다"** 블록이
`isReadingPage` 부재 · `localStorage` 미사용 · 카드 전체 링크를 **고정**한다.
방침을 되돌리려면 그 테스트부터 바꾼다(왜 없는지가 거기 적혀 있다).
